01 / The big picture

How the learning approaches differ

Machine learning (ML) is a field within artificial intelligence (AI). Algorithms identify patterns from data to make predictions, organize information, or generate new content. The learning category depends mainly on the training signal.

SupervisedUnsupervisedSelf-supervised note
Important distinction: An application domain is not the same as an algorithm type. For example, computer vision can use supervised CNNs, while generative AI can use transformer models trained with self-supervised objectives. The same architecture may be trained in different ways.

01 / REGRESSION

Linear Regression

Supervised

Models the relationship between input features and a continuous numerical outcome.

Tabular Data
How it works

It fits a line or hyperplane that minimizes the difference between predicted and actual values, commonly using least squares.

Example use case

Predicting house prices from floor area, location, and property age.

02 / CLASSIFICATION

Logistic Regression

Supervised

Estimates the probability that an observation belongs to a class.

Tabular DataNLP
How it works

It applies a logistic function to a weighted combination of features and uses a threshold or class rule to make a prediction.

Example use case

Predicting whether a bank transaction is potentially fraudulent, or classifying a review as positive or negative using text features.

03 / CLASSIFICATION & REGRESSION

Decision Tree

Supervised

Uses a sequence of feature-based questions to reach a prediction.

Tabular Data
How it works

It repeatedly splits training data into smaller groups using criteria such as information gain or Gini impurity.

Example use case

Assessing loan applications based on income, credit history, and debt level.

04 / ENSEMBLE LEARNING

Random Forest

Supervised

Combines many decision trees to produce a more stable prediction.

Tabular Data
How it works

Each tree trains on a bootstrap sample and considers a random subset of features. Predictions are combined by voting or averaging.

Example use case

Predicting customer churn from account activity and service history.

05 / MARGIN-BASED LEARNING

Support Vector Machine (SVM)

Supervised

Finds a decision boundary that separates classes with the widest possible margin.

Tabular DataComputer VisionNLP
How it works

SVM selects support vectors near the boundary. Kernel functions can represent nonlinear decision boundaries.

Example use case

Classifying emails as spam or not spam using text features, or recognizing image categories from extracted features.

06 / DEEP LEARNING

Convolutional Neural Network (CNN)

Supervised

Learns spatial patterns in images, such as edges, textures, shapes, and objects.

Computer Vision
How it works

Convolution filters scan local regions of an image to create feature maps. Deeper layers combine simple patterns into more complex representations.

Example use case

Detecting defects on a manufacturing line or identifying objects in medical images.

07 / ATTENTION-BASED DEEP LEARNING

Transformer

Often supervised fine-tuning

Processes sequences using attention to model relationships between tokens.

NLPGenerative AI
How it works

Self-attention lets each token use information from other tokens. Transformers are often pretrained with self-supervised objectives and may then be fine-tuned with labeled data or human feedback.

Example use case

Machine translation, text summarization, question answering, and large language model chat assistants.

08 / CLUSTERING

K-Means Clustering

Unsupervised

Groups observations into a chosen number of clusters based on similarity.

Tabular Data
How it works

It assigns each point to its nearest centroid, recalculates the centroids, and repeats until assignments stabilize.

Example use case

Segmenting customers according to purchasing behavior.

09 / DIMENSIONALITY REDUCTION

Principal Component Analysis (PCA)

Unsupervised

Compresses many correlated features into fewer components while retaining as much variance as possible.

Tabular DataComputer Vision
How it works

It finds orthogonal directions, called principal components, that capture the greatest variance in the data.

Example use case

Reducing hundreds of measurements before visualization or simplifying image data for analysis.

10 / DENSITY-BASED CLUSTERING

DBSCAN

Unsupervised

Finds dense groups of observations and identifies points that do not belong to a dense region.

Tabular Data
How it works

It connects points with enough nearby neighbors within a distance threshold and labels sparse points as noise.

Example use case

Detecting unusual GPS activity or discovering geographic hotspots.

11 / GENERATIVE DEEP LEARNING

Autoencoder

Unsupervised / Self-supervised

Learns a compact representation of data and reconstructs the original input.

Computer VisionGenerative AI
How it works

An encoder compresses input into a latent representation, and a decoder attempts to reconstruct it. Variational autoencoders (VAEs) add a probabilistic latent space that can be sampled to generate new data.

Example use case

Detecting unusual manufacturing images through reconstruction error, or generating image-like samples with a VAE.

Note: CNNs and transformers are neural-network architectures rather than single fixed training procedures. Their learning category depends on how they are trained. The labels above show common educational use, with qualifications where needed.

03 / Where algorithms are used

Four application domains

The same machine learning method can sometimes be adapted to more than one domain. These examples show common patterns, not strict boundaries.

▦

Tabular Data

Rows and columns such as transactions, customer records, and sensor measurements. Common methods include regression, tree models, clustering, and PCA.

▧

Computer Vision

Images and video. CNNs classify or detect visual patterns; SVMs and PCA can also support image-feature analysis.

文

Natural Language Processing

Human language in text or speech. Transformers support translation and language understanding; logistic regression and SVMs can classify text.

✧

Generative AI

Systems that create text, images, audio, or other content. Transformers generate text; VAEs and other generative architectures learn data distributions.

04 / Quick comparison

Choosing an approach

Start with the problem and the data available. The best algorithm depends on the target, data size, interpretability needs, and evaluation criteria.

GoalPossible starting pointWhy it may fit
Predict a numerical valueLinear Regression, Random ForestBoth can estimate continuous outcomes; the forest can model nonlinear patterns.
Predict a categoryLogistic Regression, Decision Tree, SVMThese methods learn decision rules or boundaries from labeled examples.
Group similar recordsK-Means, DBSCANThey discover clusters without requiring class labels.
Reduce feature countPCA, AutoencoderThey create compact representations of high-dimensional data.
Understand or generate languageTransformerAttention models relationships among tokens and supports many language tasks.
Learn or generate image representationsCNN, Autoencoder / VAECNNs learn spatial features; autoencoders learn compressed representations and VAEs can generate samples.
Practical reminder: A model should be evaluated on data it did not train on. Classification tasks often use precision, recall, and F1-score; regression tasks often use MAE or RMSE; clustering may use silhouette score alongside domain judgment.
05 / Learning reflection

What I learned

Building this framework helped me understand that machine learning algorithms are designed for different types of problems. Supervised learning uses labeled examples to predict an outcome, while unsupervised learning looks for structure in data without predefined labels. This distinction helped me see why regression and classification are useful for prediction, while clustering and dimensionality reduction are useful for exploring data.

I also learned that an algorithm's application domain is not always fixed. For example, support vector machines can be used with structured data or text features, while convolutional neural networks are especially useful for image data. Transformers have become important in natural language processing and generative AI because attention helps them model relationships across a sequence.

In future projects, I want to focus on selecting a model based on the problem and the quality of the available data instead of choosing a method only because it is popular. I also need to evaluate model performance carefully and explain what the results mean in a real-world context. This framework gives me a reference point for comparing methods as I continue learning about machine learning and AI.
